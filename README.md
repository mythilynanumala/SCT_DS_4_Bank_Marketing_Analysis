# Bank Marketing Data Analysis

## Project Overview
This project explores a bank marketing dataset using Python
to identify patterns in customer demographics and term-deposit
subscriptions.

## Objectives
- Explore customer demographics.
- Analyze job categories and account balances.
- Visualize customer age distribution.
- Compare subscription rates across customer groups.
- Examine correlations between numerical variables.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Data exploration and statistical summaries.
- Customer age distribution.
- Job category analysis.
- Account balance distribution.
- Term-deposit subscription analysis.
- Subscription analysis by job, marital status, and education.
- Correlation heatmap.

## Key Findings
The analysis summarizes customer demographics and subscription
patterns using tables and visualizations. Numerical findings
are generated directly from the dataset.

## Conclusion
This project demonstrates exploratory data analysis and data
visualization techniques using Python.
